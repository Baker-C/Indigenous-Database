# The Indigenous Database
### By Oyate Learning

The Indigenous Database is an ancillary project under the Oyate Learning Collective. This web application is aimed at improving resource sharing between Indigenous individuals, organizations, and collectives. The main objective of this project was to deliver a free, user-friendly application that enables people to easily share links to Indigenous resources such as books.

Future plans for this project include expanding our database to include other kinds of resources such as art and financial/educational resources. This project is not open source, but is done through volunteer work by people associated with Oyate Learning. 

The API is not open yet, but will be made available in the future.
